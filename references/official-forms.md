# 公文与固定格式文案

只读取并采用与当前任务对应的结构。方括号内容是占位提示，成稿时替换或保留为 `[待补充：字段]`。

## 请假条

适用结构：

```text
请假条

[称谓]：
本人因[具体且适度的原因]，拟于[开始时间]至[结束时间]请假，共[时长]。请假期间，[工作交接、紧急联系方式或课程安排]。
恳请批准。

请假人：[姓名]
[部门/班级，可选]
[日期]
```

规则：说明类型（事假、病假、年假等）、准确时间和交接安排；隐私敏感原因保持必要限度。不要将“请假申请”写成已获批准的通知。

## 请示

适用结构：

```text
关于[事项]的请示

[主送单位/领导]：
[背景与必要性。]
[拟请示的具体方案、预算、时间、责任安排及依据。]
现就[唯一或核心决策事项]请示如下：[明确请求]。

妥否，请批示。

[落款单位/姓名]
[日期]
```

规则：一事一请示；请求必须可批准、驳回或选择。若有多个方案，写明推荐方案及理由；不要预设审批结果。

## 通知

适用结构：

```text
关于[事项]的通知

[主送对象]：
为[目的/依据]，现将[事项]通知如下：
一、[时间与地点]
二、[参加人员/适用范围]
三、[具体安排]
四、[需执行事项、截止时间及联系人]

特此通知。

[发布单位]
[日期]
```

规则：把“谁、何时、何地、做什么、如何做、联系谁”写全；若内容很短，可不用分级标题。变更通知应明确原安排、变更项和生效时间。

## 申请书

适用结构：

```text
[事项]申请书

[受理对象]：
本人/本部门[身份或基本情况]，因[背景与理由]，现申请[具体事项]。
[必要依据、条件、金额、期限或实施方案。]
本人/本部门承诺[仅写有权限且能够履行的事项]。
恳请审核批准。

申请人/申请部门：[名称]
[联系方式，可选]
[日期]
```

规则：申请事项必须具体；涉及费用时写明金额、用途、测算依据和承担方式；涉及资源时写明数量、期限与归还安排。

## 通用格式差异

- “请示”强调上级作出决定；“申请书”强调申请人资格、理由与请求；“通知”用于告知并要求执行；“请假条”是个人请假凭据。
- 结语按文种选择，不混用：“妥否，请批示”用于请示；“特此通知”用于通知；“恳请批准”用于申请或请假。
- 附件存在时，在正文后写 `附件：1. [名称]`；多个附件逐项编号。
